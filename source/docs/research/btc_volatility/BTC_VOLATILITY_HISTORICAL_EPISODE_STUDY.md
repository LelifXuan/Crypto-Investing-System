# BTC Volatility Historical Episode Study

Status: `PROTOCOL_FROZEN / DATASET_PENDING`

Episode classes are bull trend, bear trend, panic crash, liquidation cascade,
volatility compression, short squeeze, macro event and crypto-specific event.
Named dates are selected from an external event chronology before feature
outcomes are viewed.

Each episode exports point-in-time Price, RV, IV, Term Structure, Skew, OI,
Funding, Liquidation and Basis panels for pre-event, event and post-event
windows.  Missing families remain visible.  The report will not infer a regime
from a single episode or use an episode selected because a candidate worked.
