# Crypto Research Terminal

**本地加密市场研究终端**——把宏观、衍生品、链上、形态结构、AI 策略整合在一个工作台里，帮你把"市场现在是什么状态、该不该动手"看清楚。

> 当前源码版本：**V2.3**（应用版本 `2.3.0`，文档更新 2026-09-30）。变更与验证记录见 [`CHANGELOG.md`](./CHANGELOG.md)；V1.6–V2.1 的演进见 [`UPDATES_V2.1.md`](./UPDATES_V2.1.md)。
> 定位：本地研究工具 + 决策辅助。**不**自动下单，**不**替代你自己的判断。

## 这个系统能帮你做什么

| 场景 | 系统提供什么 |
|---|---|
| **今天市场什么状态？** | 监控总览：宏观总分 + 技术观测 + 数据源健康，一屏看清 |
| **BTC 该不该追 / 该不该怕？** | AI 策略页扫描 5 个核心品种 × 周线、日线、4H 三个交易级别，共 15 个独立单元。周线用日线、日线用 4H、4H 用 1H K 线确定入场与首目标；交易周期结构决定止损、最终目标、预期波幅、盈亏比和杠杆预算。只有价位、执行信号和风险许可全部通过的单元才展示做多/做空并可打开详情；未通过的单元显示“无机会”，缺数据则显示“数据准备中”。后台定期生成各周期 bundle 并在发布后重算统一快照。新版波动率研究仍以影子链路验证 |
| **期权到期会不会砸盘？** | BTC 衍生品页：Call/Put Wall、Max Pain、IV、资金费率、对冲压力 |

| **A股 ETF 定投值不值？** | 行情 + 现金流/HALO 观察 + 定投/再平衡模拟 + 净值曲线 |
| **这个术语什么意思？** | 知识百科：145 个研究术语，点开即查 |

## 快速开始

### V2.3 源码启动

在 Windows 上使用 Python 3.11 或 3.14：

```powershell
cd source
py -3.14 -m venv .venv
.venv\Scripts\Activate.ps1
Copy-Item .env.example .env  # 已有本地配置时跳过
pip install -e .
cd ..
.\start.bat
```

浏览器打开 **http://127.0.0.1:8002/monitoring-page**。本地已有 `source/.env` 时，升级后确认其中的 `APP_VERSION` 为 `2.3.0`，或删去该覆盖项以使用代码默认版本。

### 便携包启动

- 解压完整压缩包，保留 `source/runtime_python/` 目录结构。
- 双击根目录的 `start.bat`。
- 浏览器打开 **http://127.0.0.1:8002/monitoring-page**。

完整便携包包含 Python 运行环境和运行依赖，无需另外安装 Python，**不包含任何密钥或凭证**；需要第三方数据源时，请自行复制 `source/.env.example` 为 `source/.env` 并填写密钥（构建器带 fail-closed secret scan 门禁，含真实密钥的归档会被拒绝生成）。使用当前源码交付时需重新构建并验证便携包。

> **历史敏感包**：2026-08-31 及更早的 PRIVATE ZIP 按当时协作要求包含真实 `source/.env`，仍只能通过可信渠道处理，禁止上传公开网盘、公开仓库或工单附件；涉及的凭证轮换要求见 [`docs/remediation/SECRET_ROTATION_REQUIRED.md`](./docs/remediation/SECRET_ROTATION_REQUIRED.md)。新构建的包不再包含 `.env`，本机开发用 `source/.env` 保留在本地、不入库也不入包。

> 数据库、日志、缓存自动生成在运行目录，无需手动处理。

## 使用建议

- **把 AI 策略当参考，不当指令**——它给的是"方向 + 触发条件 + 仓位建议"，最终决定权在你。
- **跨市场信号要降权**——A股 ETF、宏观数据与 crypto 行情是不同市场，联动只能作背景参考。
- **先看监控总览，再看具体页**——数据源状态、缓存新鲜度在总览里一眼可见，避免拿过期数据做判断。
- **知识百科随时查**——遇到不懂的术语，直接搜词条。

## 常见问题

**Q: 页面打开要等很久？**
首次启动（冷缓存）会抓取外部数据，之后有缓存会快很多。技术指标、BTC 衍生品、A股 ETF 和黄金配置页会先显示明确的 skeleton/shimmer 接入状态，真实内容在数据落地及图表绘制完成后再平滑呈现。

**Q: AI 策略页需要打开后才开始扫描吗？**
不需要。后台预计算服务定时更新各品种的策略输入，并独立发布机会矩阵快照；页面只读取已发布结果，每分钟检查一次新版本。首次启动且尚无快照时显示等待状态；旧快照会保留供参考，但更新期间不会当作新的交易信号。手动点「刷新扫描」会立即从已发布的统一策略快照重新生成矩阵，不会在浏览器请求里重算全品种策略。

**Q: 为什么 15 格都显示“无机会”，而不是给出做多或做空？**
15 格是 5 个品种 × 3 个交易级别的**扫描位置**，不保证同时有 15 笔可交易机会。方向分数只是研究倾向；系统还要检查所选交易级别的结构、低一级 K 线的进出场计划、目标与止损几何、盈亏比、杠杆预算、开仓许可及数据时效。任一交易门槛未通过，就不会列入机会排序或开放详情，避免出现有方向却没有价格点位的空计划。缺少输入时显示“数据准备中”或“数据更新中”，与已计算但无机会区分。更新源码后需重启已有后台进程，新的定时任务才会生效。

**Q: 监控总览和 AI 策略的方向如何保持一致？**
后台使用同一品种、同一周期的已发布策略判断生成总览的全局方向；技术指标仍作为证据展示，不另行发布交易方向。价格输入按原始行情时间戳筛选，形态结构分数会转换到统一量纲。策略快照尚未齐备时，总览等待后台更新；交易权限以统一策略的准入结果为准。

**Q: 某个数据源红了/空了？**
说明该数据源暂时不可用或没配 Key，系统会降级显示。检查 `.env` 里对应 Key 是否填写。

**Q: 会替我做交易吗？**
不会。本系统只做研究和决策辅助，不连接任何交易执行。
