# Crypto Research Terminal

**本地加密市场研究终端**——把宏观、衍生品、链上、形态结构、AI 策略整合在一个工作台里，帮你把"市场现在是什么状态、该不该动手"看清楚。

> 当前版本：**V2.1**（从 V1.6 的演进见 [`UPDATES_V2.1.md`](./UPDATES_V2.1.md)）
> 定位：本地研究工具 + 决策辅助。**不**自动下单，**不**替代你自己的判断。

---

## 快速开始

### 环境要求

- Windows 本地运行，Python 3.11 或 3.14

### 启动

```powershell
# 1. 创建虚拟环境并激活
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1

# 2. 配置密钥（已有 .env 的跳过这步）
Copy-Item .env.example .env

# 3. 安装依赖
pip install -e .

# 4. 启动
start.bat
```

启动后浏览器打开 **http://127.0.0.1:8002/monitoring-page** 即可开始使用。

> 数据库、日志、缓存自动生成在 `runtime/` 目录，无需手动处理。

## 使用建议

- **把 AI 策略当参考，不当指令**——它给的是"方向 + 触发条件 + 仓位建议"，最终决定权在你。
- **跨市场信号要降权**——A股 ETF、宏观数据与 crypto 行情是不同市场，联动只能作背景参考。
- **先看监控总览，再看具体页**——数据源状态、缓存新鲜度在总览里一眼可见，避免拿过期数据做判断。
- **知识百科随时查**——遇到不懂的术语，直接搜词条。

## 常见问题

**Q: 页面打开要等很久？**
首次启动（冷缓存）会抓取外部数据，之后有缓存会快很多。黄金/衍生品数据有 120 秒内存缓存 + 磁盘缓存，重启后也不慢。

**Q: 某个数据源红了/空了？**
说明该数据源暂时不可用或没配 Key，系统会降级显示。检查 `.env` 里对应 Key 是否填写。

**Q: 会替我做交易吗？**
不会。本系统只做研究和决策辅助，不连接任何交易执行。
